This is the repository accompanying the thesis "Intersectional Biases in Large Language Models: An Evaluation with Factorial Survey Experiments".

The thesis examines how large language models evaluate social targets when identities are defined by multiple social attributes. It also questions whether one-dimensional bias assessments accurately reflect intersectional evaluations. Through the integration of factorial survey experiments, the Stereotype Content Model (SCM), and multilevel variance decomposition, this thesis treats social evaluation as a structured, interrelated system rather than a collection of independent category effects, moving beyond additive notions of bias.
